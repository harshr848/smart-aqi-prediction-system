# Smart AQI Prediction System

AI-Based Air Quality Prediction and Monitoring System using Hybrid Machine Learning.

## Features

- AQI Prediction
- Hybrid ML Model
- Random Forest
- Extra Trees
- XGBoost
- LightGBM
- Voting Regressor
- Streamlit Dashboard
- AQI Meter
- 7-Day Forecast
- Health Recommendations

## Technologies Used

- Python
- Streamlit
- Scikit-Learn
- XGBoost
- LightGBM
- Pandas
- NumPy
- Matplotlib

streamlit run app.py
